# LeaderDesk People OS 다운로드

LeaderDesk People OS의 공식 Windows 설치파일 배포 저장소입니다.

최신 설치파일은 Releases에서 내려받으세요. 기존 사용자는 설치 전에 앱의 **전체 백업** 기능으로 백업 파일을 보관하세요.

## Windows에서 실행되지 않을 때

배포 파일의 SHA-256을 먼저 확인하세요.

`DD777208F4B0CA9CB6D43F83EF37EF7D88BFFD9A9ADA67AC8A525B902DAF3AA8`

해시가 일치하지만 Windows가 인터넷 다운로드 파일을 차단하면 파일을 마우스 오른쪽 버튼으로 선택해 **속성 → 차단 해제 → 적용** 후 실행하세요. 조직 PC의 보안 정책으로 실행이 막히면 사내 IT 관리자에게 위 해시와 다운로드 주소를 전달하세요.
